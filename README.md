# AI Portfolio — Александр Колесников

Персональный сайт-портфолио для позиции Junior AI Specialist / AI Automation Specialist.

## Стек

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages

## Запуск

Просто открой `index.html` в браузере.

## Публикация

Проект можно загрузить в GitHub и включить GitHub Pages в настройках репозитория.

## Изображения

Для блока AI Marketplace Design можно добавить изображения в папку `assets/` и заменить placeholder в `index.html`.

## Авторство

Содержание, структура и концепция сайта созданы Александром Колесниковым. Разработка выполнялась с использованием AI-инструментов — это намеренно отражено на самом сайте как часть AI-портфолио.
